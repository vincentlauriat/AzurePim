Private by designConfidentiel par conception

No server, no telemetryNi serveur, ni télémétrie

AzurePim talks only to management.azure.com, graph.microsoft.com and login.microsoftonline.com. No account to create.AzurePim ne parle qu'à management.azure.com, graph.microsoft.com et login.microsoftonline.com. Aucun compte à créer.

The Azure CLI keeps its own tokens; the Microsoft sign-in uses the Keychain cache of Microsoft's MSAL library.L'Azure CLI garde ses propres jetons ; la connexion Microsoft utilise le cache Trousseau de la bibliothèque MSAL de Microsoft.

InstallInstallation

A signed and notarized DMG with automatic updates is on the way. Until then, build it in two minutes (Xcode and XcodeGen required):Un DMG signé et notarisé, avec mises à jour automatiques, arrive bientôt. En attendant, compilez-le en deux minutes (Xcode et XcodeGen requis) :

git clone https://github.com/vincentlauriat/AzurePim.git && cd AzurePim
xcodegen generate
xcodebuild -project AzurePim.xcodeproj -scheme AzurePim -configuration Debug -derivedDataPath build build
open build/Build/Products/Debug/AzurePim.app
